# SABA System  
### Student Academic Behaviour Analysis System

SABA System is a web-based academic monitoring application developed to help institutions track student performance, attendance, and behaviour indicators.

The system provides separate access for **Admin**, **Teacher**, and **Student** roles.

---

## 🎯 Objective

Many institutions store academic data but do not actively analyze it to identify students who may require support.

This project helps:
- centralize academic records  
- assist teachers in tracking performance  
- provide insights to students  
- enable administrators to monitor trends  

---

## 👥 User Roles

### Admin
- Manage users  
- Monitor overall performance  
- View institutional statistics  

### Teacher
- Enter attendance  
- Enter marks  
- Update assignment status  
- Identify students needing improvement  

### Student
- View personal attendance  
- View marks  
- See behaviour evaluation  
- Receive improvement suggestions  

---

## 🧠 Core Idea

Teachers input academic data →  
System evaluates performance →  
Students receive feedback →  
Admin monitors progress.
